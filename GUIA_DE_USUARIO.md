
# Guía de funcionamiento del sistema SIRE

## 1. Acceso a la plataforma

El Sistema Inteligente de Registro de Enfermería (SIRE)
se encuentra disponible en el siguiente enlace:

https://sire-web-production.up.railway.app

### Credenciales de acceso para evaluación

- Correo electrónico: enfermera@sire.test
- Contraseña: Se proporcionara de manera privada a el docente.

## 2. Inicio de sesión

1. Ingresar al enlace de la plataforma.
2. Introducir el correo electrónico.
3. Introducir la contraseña.
4. Presionar el botón de inicio de sesión.
5. El sistema mostrará el panel principal de enfermería.

## 3. Búsqueda de estudiantes

1. Localizar el apartado de búsqueda de estudiantes.
2. Introducir un número de control.
3. Presionar el botón de búsqueda.
4. El sistema recuperará automáticamente los datos
   del estudiante desde la base de datos MySQL.

## 4. Registro de una atención

Después de localizar al estudiante, completar los
campos correspondientes a la atención de enfermería.

Ejemplo de prueba:

- Motivo de visita: Dolor de cabeza.
- Signos vitales: Presión arterial 120/80 mmHg.
- Procedimiento: Valoración inicial y reposo.
- Observaciones: Registro ficticio para evaluación.

Presionar el botón para registrar la atención.

El sistema almacenará la información en la base de
datos y mostrará un mensaje de confirmación.

## 5. Consulta del historial

1. Ingresar al apartado de historial.
2. Consultar las atenciones registradas.
3. Verificar que aparezca la atención realizada
   anteriormente.

El historial permite consultar la información de los
estudiantes y las atenciones proporcionadas.

## 6. Generación del reporte mensual

1. Localizar el apartado de reportes.
2. Seleccionar el mes y año correspondientes.
3. Presionar el botón de descarga del reporte.
4. Abrir el archivo Word generado por el sistema.

El documento se genera automáticamente utilizando
la información almacenada en la base de datos y
contiene el formato institucional correspondiente.

## 7. Cierre de sesión

Presionar el botón de cerrar sesión.

El sistema finalizará la sesión y regresará a la
pantalla de inicio de sesión.

## 8. Requisitos para utilizar la plataforma

- Conexión a internet.
- Navegador web.
- Credenciales de acceso.
- Microsoft Word o un programa compatible con DOCX
  para visualizar los reportes.

## 9. Consideraciones

Este proyecto fue desarrollado con fines académicos.
Todos los datos utilizados son ficticios.
